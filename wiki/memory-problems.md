# 忘譜時的檢查方向

本頁是練習檢查清單，不宣稱普遍的忘譜因果機制。

- 是否能從指定的中間段落開始？可透過不同起點測試。[S05-2]
- 能否辨認段落及和聲結構？可畫音樂地圖協助檢查。[S01-1]
- 左右手是否都能獨立彈奏？可先分手確認。[S05-1]
- 是否只能靠單一記憶線索？可檢查聽覺、動作、視覺、分析途徑。[S02-1]

**待確認：**「忘譜主要都是過度依賴肌肉記憶」以及「上述方法保證不忘譜」，這五篇資料不足以證明。
